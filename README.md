# KK图片排序

用于从 ComfyUI 的 `IMAGE` 批次中筛选主体/画面元素占比最大的图片。

## 节点

- `KK 主体占比筛选`
  - 输入一组图片，输出评分最高的单张图片、最佳索引、最佳评分、全部评分 JSON。
- `KK主体占比排序`
  - 输入一组图片，按主体占比从高到低输出重新排序后的图片批次、排序索引、全部评分 JSON。

## 参数建议

- `前景阈值`
  - 默认 `34`。黑底、暗底图片通常合适。
  - 漏选主体时调低，例如 `24-30`。
  - 背景杂物被选进来时调高，例如 `45-70`。
- `最小碎片面积%`
  - 默认 `0.05`。用于忽略细线、小噪点、小装饰。
  - 细碎元素误判时调高。
- `连接半径`
  - 默认 `9`。用于把临近的人物、文字、道具连接成一个主体区域。
  - 主体被分得太碎时调高。
  - 元素互相粘连太多时调低。
- `边缘残片惩罚`
  - 默认 `0.7`。用于降低贴边线条、边框、残片的得分。
- `中心偏好`
  - 默认 `0.15`。主体靠画面中心时轻微加分。

当前版本是轻量 OpenCV 方案，不需要下载模型，适合黑底、暗底、产品图、透明感海报、批量候选图筛选。
